# /auth/ 底下全是「按下去就發生事情」的路由，不是內容：
#   /auth/guest  —— 一次 GET 就建一位 User 並複製一整份示範資料（issue #66）
#   /auth/google —— 導向 Google 的 OAuth 授權頁
#   /auth/logout —— 清除 session
#
# 爬蟲跟隨它們沒有任何意義，只會在資料庫裡留下沒人用的訪客沙盒。登入頁本身是公開的，
# 而 #67（未登入一律導向 /login）落地之後，每一次爬 `/` 都會落在那一頁。
#
# 這只是「請求」，不守規矩的爬蟲照樣會來——登入頁的連結另外帶 rel="nofollow"，
# 而真正的止血是那些沙盒拿不到 cookie、沒有人用得到，加上過期訪客的定期清理。
User-agent: *
Disallow: /auth/
